# 두레이 위키 작업 문서 관리

작업 진행 시 두레이 위키에 문서를 생성하고 관리합니다.
클라이언트 가이드, 댓글 초안 등을 위키에 작성하여 사용자가 복붙할 수 있도록 합니다.

**중요**: 두레이 업무에 직접 댓글 달지 않음 → 항상 위키에 초안 작성 → 사용자가 검토 후 복붙

## 위키 정보
- **위키**: @zman 개인 위키
- **wiki_id**: `3051057878725260241`
- **기본 페이지**: claude code (`4248918788553579171`)
- **URL 형식**: `https://nhnent.dooray.com/wiki/3051057873186173159/{page_id}`

## 사용 시나리오

### 1. 새 작업 시작 시
작업명으로 하위 페이지 구조 생성:
```
claude code/
└── {작업명}/
    ├── 클라이언트_가이드    ← 클라팀 전달용 (본문에 작성)
    └── 두레이_댓글_초안     ← 두레이 댓글 복붙용 초안
```

### 두레이_댓글_초안 페이지 규칙
- **새 내용 추가**: 본문에 날짜별 섹션으로 추가 (예: `## 2026-01-22 추가 패킷 안내`)
- **본문 업데이트**: 기존 내용 + 새 내용을 통합 정리
- **업데이트 히스토리**: 본문 하단에 테이블로 기록

```markdown
## 업데이트 히스토리
| 날짜 | 변경 내용 |
|------|----------|
| 2026-01-22 | 누락된 11개 패킷 추가 |
| 2026-01-15 | 최초 작성 |
```

### 작성 시 주의사항
- **cc 태그 사용 금지**: `(cc @xxx)` 같은 태그 넣지 않음 - 사용자가 복붙 시 직접 추가
- **예시 데이터 지양**: 실제 변경된 내용만 작성, 불필요한 예시 추가하지 않음
- **두레이 직접 댓글 금지**: 절대로 dooray_project_create_post_comment 사용하지 않음

### 페이지에 포함할 정보
메인 페이지({작업명})에는 반드시 아래 정보 포함:
- **두레이 링크**: 업무 URL
- **브랜치**: feature 브랜치명 (프로젝트별로 다를 수 있음)
- **프로젝트 문서**: 각 프로젝트 docs/ 내 문서 경로 및 파일명
- **목적**: 작업 목적 간단 설명
- **커밋 이력**: 프로젝트별 날짜, 해시, 간단한 설명 (테이블 형식)

### 지원 프로젝트
- `hangame-poker-server` - 포커 게임 서버
- `gia` (gia-core, gia-poker-admin) - 어드민
- `betting_base` - 베팅 공통 라이브러리

### 템플릿 예시 (멀티 프로젝트)
```markdown
## 프로젝트 문서
| 프로젝트 | 경로 | 브랜치 |
|----------|------|--------|
| hangame-poker-server | docs/xxx.md | feature/xxx |
| gia | gia-poker-admin/docs/xxx.md | feature/xxx |
| betting_base | - | feature/xxx |

## 커밋 이력
| 날짜 | 프로젝트 | 해시 | 내용 |
|------|----------|------|------|
| 2026-01-19 | hangame-poker-server | abc1234 | 초기 작업 |
| 2026-01-19 | gia | def5678 | 어드민 API 추가 |
| 2026-01-20 | betting_base | ghi9012 | 공통 모듈 수정 |
```

### 2. 기존 작업에 문서 추가 시
해당 작업 페이지 하위에 문서 추가

## 실행 방법

### 인자가 없는 경우
claude code 페이지의 하위 페이지 목록 조회

### 인자가 있는 경우
1. **"새 작업: {작업명}"** - 새 작업 폴더 구조 생성
2. **"목록"** - 현재 작업 목록 조회
3. **"조회: {작업명}"** - 특정 작업의 페이지 목록 조회
4. **"{작업명}/{페이지명}"** - 특정 페이지 내용 조회
5. **"수정: {작업명}/{페이지명}"** - 페이지 수정 (내용은 대화로 입력받음)
6. **"댓글: {작업명}"** - 두레이_댓글_초안 페이지에 댓글 추가 (내용은 대화로 입력받음)

## API 사용

### 페이지 목록 조회
```
dooray_wiki_list_pages(project_id="3051057878725260241", parent_page_id="{page_id}")
```

### 페이지 생성
```
dooray_wiki_create_page(
    wiki_id="3051057878725260241",
    parent_page_id="{parent_id}",
    subject="{제목}",
    body="{내용}"
)
```

### 페이지 조회
```
dooray_wiki_get_page(project_id="3051057878725260241", page_id="{page_id}")
```

### 페이지 수정
```
dooray_wiki_update_page(
    wiki_id="3051057878725260241",
    page_id="{page_id}",
    subject="{제목}",
    body="{내용}"
)
```

### 위키 페이지 댓글 관리
위키 페이지 댓글 조회/작성/수정/삭제 가능

#### 댓글 조회
```
get_wiki_page_comments(wiki_id="{wiki_id}", page_id="{page_id}")
```

#### 댓글 작성
```
create_wiki_page_comment(
    wiki_id="{wiki_id}",
    page_id="{page_id}",
    content="{댓글 내용}"  # Markdown 지원
)
```

#### 댓글 수정
```
update_wiki_page_comment(
    wiki_id="{wiki_id}",
    page_id="{page_id}",
    log_id="{댓글 ID}",  # get_wiki_page_comments로 조회
    content="{수정할 내용}"
)
```

#### 댓글 삭제
```
delete_wiki_page_comment(
    wiki_id="{wiki_id}",
    page_id="{page_id}",
    log_id="{댓글 ID}"
)
```
