## 🚨 주간보고 주(週) 경계 규칙 (절대 헷갈리면 안 됨!)

**한 주 = 금요일 ~ 다음 목요일** (목요일 18:00 마감 → 금요일 리더회의 발표)

| 작업 시점 | 어느 보고서? | 예시 |
|----------|------------|------|
| 금요일 ~ 다음 수요일 | 다음 목요일 보고서 | 금 2/13 작업 → 2/19 보고서 |
| 목요일 (18:00까지) | 해당 목요일 보고서 | 목 2/19 작업 → 2/19 보고서 |

- 보고서 제목의 날짜 = 해당 주의 **마지막 날(목요일)**
- **판단 공식**: 오늘 기준 **다음 목요일 날짜** (오늘이 목요일이면 오늘)
- **코드**: `days_ahead = (3 - today.weekday()) % 7; target = today if days_ahead == 0 else today + timedelta(days=days_ahead)`
- 예: 오늘이 금 2/13이면 → 2/19 보고서 (2/12 아님!)
- 예: 오늘이 화 2/17이면 → 2/19 보고서
- 예: 오늘이 목 2/19이면 → 2/19 보고서

## 분류 목록

- **n월 점검 업무** - 이번 달 점검에 반영되는 업무
- **n월 점검 개선 업무** - 이번 달 점검 개선 사항
- **n+1월 업무** - 다음 달 점검 예정 업무
- **중장기 업무** - 언제 릴리즈할지 미정이거나, 몇 달 뒤에 반영될 업무 (예: 쿠폰API전환)
- **인프라** - 서버 환경, 장비, 배포 관련
- **기타업무** - 릴리즈에 반영할 컨텐츠라고 하기엔 애매한 작은 사이즈 작업, 또는 개발환경자동화처럼 개인적으로 한 업무
- **회의** - 참석한 회의
- **휴가** - 휴가/오프데이
