## 🚨 주간 기간 계산 규칙 (절대 준수)

**한 주 = 금요일 ~ 다음 목요일**

- 보고서 제목 날짜 = 해당 주의 **마지막 날(목요일)**
- **판단 공식**:
  ```python
  from datetime import date, timedelta
  today = date.today()
  days_ahead = (3 - today.weekday()) % 7
  target_thursday = today if days_ahead == 0 else today + timedelta(days=days_ahead)
  week_start = target_thursday - timedelta(days=6)  # 금요일
  week_end = target_thursday                         # 목요일
  ```
- 예: 오늘이 월(2/23) → 이번 주 금(2/20) ~ 목(2/26), 목요일 날짜(2/26)가 보고서 날짜

## 보고서 제목 형식

```
[주간보고] 이태양_26년_{N}월 {X}주 ({시작일}~{종료일})
```

예시: `[주간보고] 이태양_26년_2월 5주 (2/20~2/26)`

**X주 계산**: 해당 월의 몇 번째 목요일인지 기준

### STEP 4. 섹션별 업무 분류

#### 섹션 1 — 주간 이슈 및 업무 (이번 주 활동 있는 것만!)

⚠️ **핵심 필터링 규칙**: 아래 두 조건 중 하나라도 해당하는 업무만 포함

1. **업무 `updatedAt`** 이 이번 주 기간(week_start ~ week_end) 내인 경우
2. **이번 주에 댓글**이 달린 경우 → `get_post_comments()` 로 확인

확인 방법:
```
1. 수집된 업무들의 get_full_detail_of_task_by_id() 로 updatedAt 확인
2. updatedAt이 이번 주가 아닌 업무는 → get_post_comments() 로 댓글 날짜 확인
3. 둘 다 이번 주 활동 없으면 → 섹션 1에서 제외
```

- `(리소스)` — 리소스 취합, 일정 조율
