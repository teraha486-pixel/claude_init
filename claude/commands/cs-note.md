# CS노트 작성 스킬

고객센터 전달용 CS노트 xlsx 파일을 작성한다.

## 실행 시 사용자에게 질문

스킬 호출 시 아래 정보를 사용자에게 질문한다:

1. **두레이 업무 링크** — 변경 사항이 기재된 업무 URL
2. **기획서 파일** (선택) — 참고할 기획서 파일명 또는 경로 (없으면 업무 본문만으로 작성)
3. **파일명** (선택) — CS노트 파일명을 지정하고 싶은 경우. 미지정 시 자동 생성

## 작업 절차

### 1단계: 정보 수집

- 두레이 업무 `get_full_detail_of_task_by_id`로 상세 조회
- 기획서 파일이 있으면 python-pptx 등으로 텍스트 추출하여 내용 파악

### 2단계: 템플릿 복사

- 템플릿 경로: `C:\Users\NHN\Desktop\기획\와이키키\자료\CS노트_기본_템플릿.xlsx`
- 바탕화면(`C:\Users\NHN\Desktop\`)에 파일명을 지정하여 복사
- 파일명 규칙: `CS노트_{서비스명}_{기능 요약}_{작성일YYYYMMDD}.xlsx`
  - 예: `CS노트_포커공통_길드전 1성 도시 추가 오픈_20260318.xlsx`

### 3단계: 필수입력 시트 채우기

openpyxl로 `필수입력` 시트의 아래 셀을 채운다:

| 셀 | 항목 | 설명 |
|----|------|------|
| E4 | 작성일 | YYYY.MM.DD 형식 |
| C5 | 서비스명 & 기획 타이틀 | [포커공통] 등 서비스명 + 기능 타이틀 |
| C7 | 적용 일시/기간 | 점검일 또는 적용 기간 |
| C10 | 서비스변경 사유 | 변경 배경을 고객 관점에서 간결하게 |
| C11 | 내용 | 상세 변경 내용 (아래 작성 가이드 참고) |

### 4단계: 내용(C11) 작성 가이드

고객센터 상담원이 이해할 수 있는 고객 관점에서 작성한다:

```
1. 변경 배경 (또는 신규 추가 배경)
   - 왜 변경하는지 간단히

2. 변경 내용 (또는 신규 내용)
   [변경 전] / [변경 후] 또는 상세 스펙 정리

3. 유지되는 사항 (있는 경우)
   - 변경되지 않는 부분 명시

4. 적용 대상
   - PC포커, 포커 클래식, 한게임홀덤 등

5. 예상 문의 및 응대 가이드
   Q. 예상 질문
   A. 응대 답변
   (2~3건 작성)
```

### 5단계: 결과 보고

- 작성 완료된 파일 경로 안내
- 채워 넣은 주요 항목 요약 테이블 출력
