## STEP 1: 데이터 수집

guild_chat 테이블 조회 (alpha-game DB):

```sql
SELECT seq, reg_date, guild_id, guild_name,
       member_id, member_no, nickname, message, message_type
FROM guild_chat
WHERE reg_date BETWEEN '{날짜} 00:00:00' AND '{날짜} 23:59:59'
  AND message_type = 0
ORDER BY reg_date
```

- 날짜 미지정 시 어제 사용
- `message_type = 0`: 일반 채팅만
- `guild_chat_all.json`으로 저장

## STEP 2: 전처리 (문맥 연결)

**스크립트**: `/Users/nhn/temp/guild_chat/prepare_llm_data.py`

1. 길드별 시간순 정렬
2. 같은 `member_id` + 5분 이내 연속 메시지 → ` / ` 구분자로 연결 (최대 300자)
3. **전수 분석용 전체 목록 생성** (샘플링 하지 않음)

출력 형식:
```json
{
  "total_messages": 606,
  "total_contexts": 335,
  "sample_size": 335,
  "samples": [{"id": 1, "guild": "길드명", "nickname": "닉네임", "message": "연결된 메시지"}]
}
```

파일명: `llm_samples_{날짜}.json`

> **중요**: 100건 샘플링은 조직적 RMT를 6.5배 과소추정. 전수 분석 필수.

## STEP 3: LLM 전수 분석 (배치 처리)

전체 메시지를 ~112건씩 배치로 나누어 분석 후 결과 병합.

### 배치 분할

```
전체 335건 → 3배치
- 배치 1: ID 1~112 (112건)
- 배치 2: ID 113~224 (112건)
- 배치 3: ID 225~335 (111건)
```

### 분석 프롬프트 핵심

```
게임 커뮤니티 데이터 분석 전문가로서 {N}건의 길드 채팅 메시지를 분석하세요.

## 분석 원칙
1. 자유 분류: 고정 카테고리 없이 패턴 자유 발견
2. 정량화: 건수 → 비율(%) → 월 추정치
3. 감성 점수: -5(매우 부정) ~ +5(매우 긍정)
4. 심각도: 높음/중간/낮음
5. 액션 가능: 모든 인사이트에 구체적 조치 제안

## 필수 분석 영역
- RMT(현금거래) 탐지: 전화번호/카톡ID/띄어쓰기 우회/이벤트 위장
- 이탈 위험 신호: 대규모 손실, 게임 흥미 상실, 혼자 활동 불만
- 공정성 의심: 작업장(짱구)/봇/조작 의심
- 같은방 갈등: 길드원끼리 같은방 진입으로 인한 분쟁
- 콘텐츠 반응: 길드전 도시별, 보상 시스템, 이벤트
- 커뮤니티 문화: 암묵적 규칙, 에티켓, 갈등, 리더십, 오프라인 확장
- 감성 분포: 긍정/중립/부정/미분류 비율 + 키워드
- 기획팀 인사이트: 주제 + 데이터 근거 + 구체적 제안
```

### 배치 결과 병합

각 배치 JSON 결과(`llm_full_batch{N}.json`)를 하나로 병합:
- 동일 카테고리 건수/샘플 합산
- 업자 프로필 중복 제거 (전화번호/카톡ID 기준)
- 감성 분포 전체 재계산
- 기획 인사이트 우선순위 재정렬

최종 파일: `insight_analysis_{날짜}_full.json`

## STEP 4: HTML 리포트 생성

JSON → 시각적 HTML 리포트 변환.

### 리포트 구성

1. **헤더**: 모델명, 날짜, 전체/문맥연결/길드 수, `전수분석` 배지
2. **요약 카드 6개**: RMT(빨강) / 이탈 위험(노랑) / 같은방 갈등(주황) / 공정성(보라) / 긍정 경험(초록) / 기획 인사이트(파랑)
3. **RMT 섹션**: 업자별 프로필 카드 (전화번호, 활동 길드 태그, 닉네임 변형 태그, 수법), 우회 패턴 원문
4. **같은방 갈등**: 탈퇴 요구 사례, 규칙 설명 사례, 매칭 회피 시스템 필요성
5. **이탈 위험**: 대규모 손실(금액 포함) + 길드 활동 불만
6. **공정성 의심**: 작업장 패턴 유저 묘사 원문
7. **콘텐츠 반응**: 도시별 감성, 보상 반응, 오프라인 모임
8. **커뮤니티 문화**: 길드전 리더십, Pro 길드 모범사례, 다중 길드 운영
9. **감성 분포**: 가로 바 차트 (긍정-중립-부정-미분류) + 키워드
10. **기획 인사이트**: 우선순위 배지 (긴급/높음/중간) + 근거 + 제안 카드

## RMT 탐지 패턴 (2026-02-05 기준)

### 기존 패턴
```
전화번호: 010[-\s~]?\d{4}[-\s~]?\d{4}
카톡ID: 카톡\s*[a-zA-Z0-9]+
현금거래: 판매|매입|사고팔고|현금|환전
```

### 새로 발견된 우회 패턴
```
띄어쓰기 우회: '거 래', '판 매' (글자 사이 공백)
이벤트 위장: '[길드명] 전원분들께 N억씩 지원' + 전화번호
닉네임 내장: 닉네임에 '카톡xxx' 포함 (카톡max4982, 까톡max4982)
쿠폰 유인: '배민쿠폰', '커피쿠폰' + 카톡ID
다중 길드 동시: 동일 메시지를 4개+ 길드에 동시 배포
```

### 조직적 RMT 식별 기준
- 동일 전화번호가 2개+ 길드에서 노출
- 닉네임 변형이 3개+ (카톡xxx, 까톡xxx, 깨톡xxx)
- 동일 문구를 다른 길드명만 바꿔서 배포

## 감성 점수 기준

| 점수 | 의미 | 예시 |
|------|------|------|
| +5 | 매우 긍정 | "대박! 길드전 1위!" |
| +3~+4 | 긍정 | "보상으로 50억 이김 ㅋㅋ" |
| +1~+2 | 약간 긍정 | "편하게 런던으로 갑니다" |
| 0 | 중립 | "안녕하세요", "길드전 참여 부탁" |
| -1~-2 | 약간 부정 | "겜안되더라" |
| -3~-4 | 부정 | "겜할맛도별루안나" |
| -5 | 매우 부정 | "3000억 꼬름 / 핸드폰 박살" |

## 정량화 계산

```
발견율(%) = 해당 패턴 건수 / 전수 분석 총 건수 × 100
일 추정치 = 전체 메시지 수 × (발견율 / 100)
월 추정치 = 일 추정치 × 30
```
