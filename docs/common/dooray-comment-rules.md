# Dooray 댓글 작성 규칙

## 멘션 형식
- `@이름님` 형식으로 작성
- 직급은 내가 추가하라고 할 때만 추가

## 필수 규칙
1. 댓글 마지막에 항상 cc로 **이상민님** 추가

## 댓글 예시
```markdown
@OOO님

요청하신대로 수정했습니다.

**수정 내용:**
- 내용 1
- 내용 2

커밋: `abc1234`

cc. @이상민님
```

## 멤버 ID
| 이름 | ID | 비고 |
|------|-----|------|
| 이상민 | 1552493835551450806 | 항상 cc |
| 이태양 | 2802458672652277190 | 나 |

# Git 커밋 규칙

## 프로젝트별 커밋 메시지 prefix
아래 프로젝트는 커밋 시 **[태양]** prefix 필수:
- `gia`
- `betting-base`
- `hangame-poker-server`

## 주의사항
- `Co-Authored-By` 넣지 않기

## 커밋 예시
```
[태양] 게임머니 이력 조회 API에서 orderNo 파라미터 제거
```
